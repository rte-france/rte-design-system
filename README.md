## Content

RTE's design system

## Usage

1. Clone project code.

```bash
git clone https://github.com/rte-france/rte-design-system.git
cd rte-design-system
```

## React

1. Docs
   see documentation [here](packages/rte-design-system-react/README.md)

2. Installation dependence.

```bash
cd packages/rte-design-system-react/
npm install
```

3. Start local server.

```bash
cd sites/rte-design-system-site-react/
npm run dev
```

## Angular

1. Docs
   see documentation [here](packages/rte-design-system-angular-build/README.md)

2. Installation dependence.

```bash
cd packages/rte-design-system-angular-build/
npm install
```

3. Start local server.

```bash
cd sites/rte-design-system-site-angular/
ng serve
```
